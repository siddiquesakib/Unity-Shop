## ✦ Overview & Vision

> **Build • Manage • Sell • Scale — All in One Platform**

**Unity Shop** is a production-ready, enterprise-level multi-vendor marketplace designed to break down borders and connect buyers and sellers seamlessly. Unlike traditional demo-based e-commerce projects, Unity Shop focuses on scalability, performance, security, and real-world business logic, making it directly adaptable for commercial deployment.

From searching for a product by one’s own language and currency preference to viewing the desired product and negotiating to buy it via a reliable payment system. Users can track their orders live and lean on our **24/7 AI-powered after-sales support**. Backed by a structured and dedicated role-based system, Unity Shop is secure, market-ready, and built for immense growth.

### 🚀 Vision

To build a complete digital commerce infrastructure that empowers businesses to:

- ✅ **Sell products effortlessly**
- ✅ **Manage operations efficiently**
- ✅ **Track business growth intelligently**
- ✅ **Scale without technical bottlenecks**

## ⚡ Key Features & Offerings

### ✨ Core Platform Capabilities

| Feature                       | Description                                                                                       |
| ----------------------------- | ------------------------------------------------------------------------------------------------- |
| 🌍 **Localization Engine**    | Browse products in your native language and preferred currency (Google Translate integrated).     |
| 💬 **AI Negotiations**        | Don't like the price? Haggle with our **AINegoBot** in real-time to secure a better deal.         |
| 🚚 **Live Order Tracking**    | Real-time granular tracking from Processing → Packaging → Shipping → Delivered.                   |
| 🛍️ **Multi-Vendor Ecosystem** | Dedicated portals for sellers to manage inventory, track revenue, and handle orders autonomously. |
| ⭐ **Group Purchasing**       | Community-driven bulk-buying mechanisms unlocking massive tier-based discounts.                   |
| 💳 **Secure Payments**        | Fully integrated reliable payment gateways with foolproof webhook validation.                     |

### 🛍️ Intelligent Commerce Modules

- **Intelligent Shopping Cart System:** Persistent cart across sessions, automatic price recalculation, coupon & discount integrations, and session + account synchronization.
- **Secure Checkout & Payment Flow:** Multi-step checkout process with address management, order verification pipeline, and real-world transaction validation.
- **Complete Order Lifecycle Management:** Full operational order workflow ensuring transparency and accountability _(Order → Confirmation → Processing → Packaging → Shipping → Delivered → Completed)_.
- **Automated Invoice Generation (PDF):** Auto-generated professional invoices featuring company branding, complete order breakdown, and download capability.
- **Coupon & Campaign Engine:** Time-based discount campaigns, category-specific promotions, and seasonal marketing automation.
- **Advanced Admin Dashboard:** Real-time sales metrics, user behavior analysis, seller performance tracking, revenue breakdown, and data-driven business insights.

## 🤖 AI Intelligence & WebSockets

Unity Shop removes the friction of online shopping by deploying **SmartAI** directly into the retail journey:

1.  **AINegoBot:** A state-of-the-art bargaining engine. Customers can place bids, and the bot calculates profit margins, historical seller data, and threshold parameters to accept, counter, or reject offers instantly via WebSockets.
2.  **24/7 Post-Sales Support:** Need to process a return? The AI conversational agent handles standard inquiries immediately without human bottlenecks.
3.  **CostEngine Heuristics:** AI-driven weight and distance calculations providing pinpoint delivery estimates.
4.  **SmartAI Product Advisor:** Acts as a virtual shopkeeper, learning from product-specific structured & unstructured data to assist users with context-aware Q&A, feature explanations, and product comparisons.

## 🏗 Tech Stack & Architecture

### 🖥 Frontend Architecture

| Technology           | Role           | Description                                                              |
| -------------------- | -------------- | ------------------------------------------------------------------------ |
| **Next.js 16**       | Core Framework | High-performance SSR/SSG hybrid offering phenomenal SEO & edge delivery. |
| **React 19**         | UI Library     | Next-gen progressive rendering & state management.                       |
| **TailwindCSS v4**   | Styling        | Lightning-fast JIT compilation for a clean, cohesive design system.      |
| **Framer Motion**    | Animations     | Fluid page transitions, micro-interactions, and engaging layout shifts.  |
| **Socket.io Client** | Real-time Data | Powers live bid updates, active product viewer counts, and order pulses. |

### ⚙️ Backend Infrastructure

| Technology              | Role        | Description                                                              |
| ----------------------- | ----------- | ------------------------------------------------------------------------ |
| **Node.js + Express 5** | API Gateway | Rock-solid asynchronous runtime with modern routing & middleware.        |
| **MongoDB + Mongoose**  | Database    | Flexible NoSQL doc storage ideal for diverse product catalogs & history. |
| **Socket.io**           | WebSockets  | Bi-directional event-driven communication for chat, tracking, and bids.  |
| **Cloudinary**          | Media CDN   | Global edge-delivery network for optimized seller media caching.         |
| **OpenAI / Gemini API** | AI LLMs     | The brains behind our automated support ops and dynamic negotiation bots |

### 🏛️ Architecture Highlights — Why Next.js?

- **🚀 Performance Optimization:** Faster load times via SSR (Server-Side Rendering) and SSG (Static Site Generation) resulting in superior SEO and higher conversion rates.
- **🏢 Enterprise-Grade Features:** Built-in API routes, Edge functions, and React Server Components.
- **⚡ Scalable Deployment:** Ready for auto-scaling deployments and global edge content delivery.

## 📁 Folder Structure

### Frontend — `Unity-Shop/`

```text
Unity-Shop/
├── src/
│   ├── app/
│   │   ├── (auth)/         # Secure authentication & NextAuth flows
│   │   ├── (payment)/      # Webhook callback handlers for active transactions
│   │   ├── dashboard/      # Role-gated panels (Admin, Manager, Delivery, Seller, User)
│   │   ├── products/       # Rich SSR product display and category catalogs
│   │   └── api/            # Serverless Next.js proxy endpoints
│   ├── components/         # Reusable UI: AINegoBot, Language Switcher, Providers
│   ├── contexts/           # Global Contexts: Auth, Cart, Currency, Sockets
│   └── lib/ & utils/       # Utility instances, order lifecycle managers
```

### Backend — `UnityShop-Sever/`

```text
UnityShop-Sever/
├── index.js                # Core API routing & server instantiation
├── routes/                 # API controllers for Auth, AI, Products, Orders, GroupBuy
├── middleware/             # Hardened JWT validators and RBAC guards
├── models/                 # Mongoose schemas (Negotiation, Products, Roles, Users)
├── sockets/                # Active WebSocket handlers for live presence & chat
└── utils/                  # Cloudinary sync utilities and AI prompt engineering
```

## ⚙️ Getting Started

### Prerequisites

[![Node](https://img.shields.io/badge/Node.js-%E2%89%A518-339933?style=flat-square&logo=node.js)](https://nodejs.org/)
[![npm](https://img.shields.io/badge/npm-%E2%89%A59-CB3837?style=flat-square&logo=npm)](https://npmjs.com/)
[![MongoDB](https://img.shields.io/badge/MongoDB-Atlas_Account-47A248?style=flat-square&logo=mongodb)](https://mongodb.com/atlas)

### Installation

1. **Clone the repository**

```bash
git clone https://github.com/siddiquesakib/Unity-Shop.git
cd Unity-Shop
```

2. **Setup Frontend**

```bash
cd Unity-Shop
npm install
npm run dev
# Server spins up at http://localhost:3000
```

3. **Setup Backend**

```bash
cd ../UnityShop-Sever
npm install
npm run dev
# Server spins up at http://localhost:5000 (adjust per your env)
```

### 🔑 Environment Variables

To run the project, duplicate the `.env.example` files or create new `.env` and `.env.local` files.

**Frontend (`Unity-Shop/.env.local`)**

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
NEXT_PUBLIC_SOCKET_URL=http://localhost:5000
NEXTAUTH_SECRET=your_nextauth_secret
NEXTAUTH_URL=http://localhost:3000
```

**Backend (`UnityShop-Sever/.env`)**

```env
PORT=5000
MONGODB_URI=mongodb+srv://...
JWT_SECRET=your_jwt_strong_secret
OPENAI_API_KEY=sk-...
GEMINI_API_KEY=AIzaSy...
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_key
CLOUDINARY_API_SECRET=your_secret
```
